# THE TIMELINE — 턴제 거리 결투

싱글플레이와 1 대 1 PvP가 같은 무기, 카드, Peak 룬 구성을 사용하는 브라우저 게임입니다. Cloudflare Worker가 정적 화면을 제공하고 Durable Object가 PvP 방과 라운드 결과를 판정합니다.

## 실행과 배포

Node.js 20 이상에서 `npm ci`, `npm run check`, `npm run dev` 순서로 로컬 확인이 가능합니다. Cloudflare 연결 배포의 빌드 명령은 `npm ci && npm run build`, 배포 명령은 `npx wrangler deploy`입니다. 설정은 `wrangler.jsonc`에 있습니다.

`index.html`의 무기·카드·Peak 정의가 원본입니다. `npm run build`는 이 정의에서 `src/turn-rules.generated.js`를 만들고, 화면과 이미지 자산을 `dist/`에 복사합니다. 생성 파일은 직접 수정하지 않습니다.

## 게임 규칙

- 각 무기는 카드 8장의 기본 덱을 제공합니다. 시작 전에 카드를 교체하고 Peak 룬을 최대 3개까지 선택할 수 있습니다.
- 전투장은 5칸이며 같은 칸은 거리 0, 양 끝은 거리 4입니다. 두 캐릭터의 실제 칸 위치를 싱글과 PvP가 같은 규칙으로 처리합니다.
- 가장자리에서 후퇴하면 남은 공간만큼 상대를 반대쪽으로 밀어 거리를 벌립니다. 양쪽이 이미 끝 칸에 있으면 더는 움직이지 않습니다.
- 내 턴에 내 카드 한 장을 실행한 다음 상대 턴에 상대 카드 한 장을 실행합니다. 공격 예고는 다음 자기 턴마다 1틱씩 줄어들고 0이 되는 턴에 발동합니다.
- 공격은 카드에 표시된 다섯 개 거리 네모 중 켜진 칸에서만 적중합니다. 사거리가 없는 이동·방어 카드는 모든 네모가 켜집니다.
- 상단 공격은 하단 자세에 강하고, 하단 공격은 상단 자세에 강합니다. 방어 카드의 막기는 다음 상대 턴에 적용됩니다.
- 싱글플레이는 10단계 연속 전투입니다. 1~9단계 승리 뒤 새 카드 2종 또는 체력 회복 중 하나를 고르고, 10단계에서 보스와 싸웁니다. 체력과 획득 카드는 다음 단계로 이어집니다.
- 다섯 전투 배경 중 하나가 새 전투마다 무작위로 선택됩니다. PvP는 서버가 고른 같은 배경을 양쪽에 보여 줍니다.
- 예고 정보는 캐릭터 발밑 말풍선의 카드 이름·남은 틱으로 표시하고, 말풍선에 마우스를 올리거나 키보드로 초점을 주면 카드 설명을 볼 수 있습니다. 싱글플레이는 상대의 다음 카드를 먼저 보여 주고, PvP에서는 상대가 예고를 시작한 뒤 공개합니다.
- 싱글플레이의 전투 및 단계 사이 보상 선택은 브라우저 로컬 저장소에서 이어할 수 있습니다.
- 전투 손패는 중복된 카드 종류를 한 번만 표시하고, 상단의 현재 턴은 양쪽 행동마다 증가합니다.
- 튜토리얼은 실제 전투 화면에서 이동·방어·예고 공격을 따라 하는 19단계 연습이며 기존 저장을 변경하지 않습니다. 지시 대상 이외 영역은 흐리게 가리고 클릭을 차단합니다.
- 이동과 공격·피격 이미지를 디코딩까지 미리 준비하고, 각 프레임을 일반 속도 320ms(빠름 240ms) 동안 유지한 뒤 다음 행동을 재생합니다.

PvP는 `POST /api/rooms`, `POST /api/rooms/:code/join`, `GET /ws/:code?token=...`를 사용합니다. 방 생성·입장 시 무기, 카드 8장, Peak 선택을 서버가 검증합니다.
