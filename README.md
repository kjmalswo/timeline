# THE TIMELINE — 두뇌 서바이벌

2~8명의 참가자가 실시간 문제를 풀며 승점을 쌓는 온라인 생존 게임입니다. 메인 라운드마다 한 명씩 탈락하고, 마지막 두 참가자는 세 가지 결승 문제로 우승자를 가립니다.

## 실행과 배포

Node.js 20 이상에서 `npm ci`와 `npm run dev`를 실행하면 로컬 개발 서버가 열립니다. `npm run build`는 단일 화면을 `dist/`에 복사합니다. Cloudflare 배포 설정은 `wrangler.jsonc`에 있습니다.

## 게임 진행

- 타이틀에서 방을 만들고 최대 인원 2~8명을 정합니다. 초대 코드를 공유해 참가자를 모은 뒤 방장이 시작합니다.
- 라운드 문제는 메모리, 공개 계산, 비공개 단서 추리, 용의자 지목, 임시 팀전 중 무작위로 선택됩니다.
- 메모리 문제는 6자리 순서를 외운 뒤 입력합니다. 공개 계산은 모두 같은 수식을 풉니다. 비공개 단서와 팀전은 각 참가자에게 필요한 정보만 전달합니다.
- 답은 서버가 정한 시간 안에 한 번 제출하며, 제출 내용은 답변 마감 전까지 다른 참가자에게 공개하지 않습니다.
- 본선은 매 라운드 승점이 가장 낮은 참가자 한 명을 탈락시킵니다. 현재 라운드 승점이 같으면 누적 승점, 다시 동점이면 서버가 정한 무작위 순서로 탈락자를 정합니다.
- 두 명이 남으면 메모리·계산·불완전정보·추리 문제로 3회 결승을 진행합니다. 결승 승점이 가장 높은 참가자가 우승합니다.

## 실시간 동기화

방과 게임 상태는 Cloudflare Durable Object 한 곳에서 관리합니다. 방 변경과 답안 제출을 직렬 처리하고, 매 게임 상태에 순번과 라운드 식별자를 붙여 중복 제출과 오래된 답안을 거부합니다. WebSocket 재접속은 플레이어 토큰으로 기존 자리에 이어집니다. 문제 타이머는 클라이언트 시계가 아니라 서버 마감 시각과 Durable Object 알람으로 처리합니다.

방 생성은 `POST /api/rooms`, 입장은 `POST /api/rooms/:code/join`, 실시간 연결은 `GET /ws/:code?token=...`을 사용합니다.
