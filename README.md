# TIMELINE — 두뇌 서바이벌

1인 훈련과 2~8인 온라인 대전을 지원합니다.

## 실행·배포

Node.js 20 이상:

```sh
npm ci
npm run dev
```

- `npm run build`: 화면을 `dist/`에 빌드
- `npm run deploy`: Cloudflare 배포
- `main` 변경 시 연결된 Cloudflare 자동 배포 실행

## 게임 방식

- **1인 훈련:** 10문제. 논리·정보·전략·관찰 분야를 다룬 뒤 취약 분야를 우선하고 제한 시간을 조정합니다. 제출 후 해설과 분야별 결과를 제공합니다.
- **2인 대전:** 서로 다른 유형의 10문제 결승.
- **3~8인 대전:** 본선에서 최저 라운드 승점 참가자가 탈락하고, 마지막 두 명은 서로 다른 유형의 3문제 결승. 결승 누적 승점으로 우승자를 정합니다.

## 문제·화면

10개 새 유형을 사용하며 직전 유형은 반복하지 않습니다. 방송 두뇌 게임의 추론·선택·심리전에서 영감을 얻은 자체 문제입니다.

- **추리·퍼즐:** 가짜 동전, 진실 두 개와 숨겨진 칩, 다섯 자리 배치, 스위치, 보석 탈출 경로, 세 사람 팀 편성, 수식 배틀, 도형 합성, 높은 카드의 함정.
- **심리전:** 낮은 숫자 독식. 숫자 하나를 동시에 비공개로 고르고, 겹치지 않는 가장 낮은 숫자가 6점을 얻습니다. 1인 훈련은 가상 상대 세 명과 진행합니다.

인디고 블루·골드 테마로 **현재 라운드 → 목표 → 규칙·예시 → 문제 자료 → 보기**를 표시합니다. 모든 문제는 보기 하나를 고른 뒤 제출합니다. 기본 제한 시간은 유형별 90~180초이며, 훈련 성과에 따라 0.9~1.25배로 조정합니다.

추리 문제는 정답 4점, 가장 빠른 정답은 1점 추가입니다. 미제출은 0점입니다. 큰 고정 타이머와 마지막 30초의 빨간 비네트·시계 효과음을 제공합니다. 마지막 10초는 소리가 빨라지고, 효과음은 끌 수 있습니다. 제출·종료 뒤에는 경고가 멈춥니다. 판정과 타이머는 서버가 관리하며 재접속하면 기존 자리에 이어집니다.

화면: `index.html` · 서버: `src/worker.js` · 배포 설정: `wrangler.jsonc`
