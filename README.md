# TIMELINE — 두뇌 서바이벌

1인 훈련과 2~8인 온라인 대전을 지원합니다.

## 실행·배포

Node.js 20 이상:

```sh
npm ci
npm run dev
```

- `npm run build`: 화면을 `dist/`에 빌드
- `npm run deploy`: Cloudflare 배포
- `main` 변경 시 연결된 Cloudflare 자동 배포 실행

## 게임 방식

- **1인 훈련:** 10문제. 네 분야를 다룬 뒤 취약 분야를 우선하고 제한 시간을 조정합니다. 제출 후 해설과 분야별 결과를 제공합니다.
- **2인 대전:** 서로 다른 유형의 10문제 결승.
- **3~8인 대전:** 본선에서 최저 라운드 승점 참가자가 탈락하고, 마지막 두 명은 서로 다른 유형의 3문제 결승. 결승 누적 승점으로 우승자를 정합니다.

## 문제·화면

18개 유형을 사용하며 직전 유형은 반복하지 않습니다.

- **완전정보:** 교차 수열, 기호 연립식, 순위·표식 논리, 5×5 좌표 변환, 6×6 스도쿠, 5자리 암호.
- **불완전정보:** 더블덱 인디안 포커, 상황 추리, 가중 순위 추론, 반복키 암호, 표본 확률, 자원 최적화, 봉인 경매, 참·거짓 판별, 16자리 기억, 타일 전략, 최단 경로, 8비트 상태 추론.

인디고 블루·골드 테마로 **현재 라운드 → 문제 → 조건/힌트**를 표시합니다. 개인 단서는 별도로 보여주며, 대전에서는 공개 대화로 공유할 수 있습니다.

미제출은 0점, 타일 전략 시간 초과는 자동 선택입니다. 판정과 타이머는 서버가 관리하며 재접속하면 기존 자리에 이어집니다.

화면: `index.html` · 서버: `src/worker.js` · 배포 설정: `wrangler.jsonc`

수정·배포 작업 규칙은 [AGENTS.md](AGENTS.md)를 따릅니다.
