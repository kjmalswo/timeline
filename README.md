# THE TIMELINE — 두뇌 서바이벌

2~8명의 참가자가 실시간 문제를 풀며 승점을 쌓는 온라인 생존 게임입니다. 본선 라운드마다 승점이 가장 낮은 한 명이 탈락하고, 마지막 두 참가자는 서로 다른 세 문제의 결승을 치릅니다.

## 실행과 배포

Node.js 20 이상에서 `npm ci`와 `npm run dev`를 실행하면 로컬 개발 서버가 열립니다. `npm run build`는 화면을 `dist/`에 복사합니다. Cloudflare 배포 설정은 `wrangler.jsonc`에 있습니다.

## 문제 유형과 진행

매 라운드는 완전정보와 불완전정보 분야 중 하나를 같은 확률로 고르고, 직전 문제 유형은 바로 반복하지 않습니다. 난이도는 상·최상으로 표시합니다.

- 완전정보 퍼즐은 ‘문제적 남자’ 계열의 두뇌 문제에서 착안한 수열 규칙, 기호 연립식, 순위 논리 그리드, 공간 좌표 변환으로 구성됩니다.
- 불완전정보는 인디안 포커(52장 더블덱), 바다거북스프 사건 추리, 비공개 순위 공유, 키 조각 암호, 표본 확률전, 자원 최적화, 봉인 경매, 참·거짓 판별, 개인별 작업 기억, 비공개 목표 턴제 드래프트, 분할 지도 최단 경로, 비트 상태 전이 추론을 포함합니다.
- 각 유형은 선택형·정수·문자열·베팅·입찰 입력을 사용합니다. 인디안 포커의 중복 카드와 숨겨진 개인 정보, 경매의 비공개 가치, 전략전의 순차 타일 선택은 서버에서 판정합니다.
- 비공개 단서 문제에서는 게임 내 공개 대화로 단서와 협상 내용을 공유할 수 있습니다. 대화는 참가자 토큰으로 검증하고 240자 제한 및 전송 간격을 둡니다.
- 시간 초과 시 답을 제출하지 않은 참가자는 0점이며, 턴제 전략전은 차례가 지나가도록 서버가 남은 타일을 자동 선택합니다.
- 본선은 라운드 승점을 먼저 비교하고, 동점이면 누적 승점과 서버가 정한 무작위 순서로 탈락자를 정합니다.
- 두 명이 남으면 문제 유형 중 서로 다른 세 가지를 뽑아 결승을 진행합니다. 결승 누적 승점이 가장 높은 참가자가 우승합니다.

## 실시간 동기화

방과 게임 상태는 Cloudflare Durable Object 한 곳에서 관리합니다. 방 변경, 답안, 채팅, 턴 행동을 직렬 처리하고 게임 순번과 라운드 식별자로 오래된 제출을 거부합니다. WebSocket 재접속은 플레이어 토큰으로 기존 자리에 이어집니다. 타이머는 서버 마감 시각과 Durable Object 알람으로 처리합니다. 문제 형식이 바뀐 배포에서는 이전 형식의 저장된 방을 새 규칙으로 잘못 읽지 않도록 폐기합니다.

방 생성은 `POST /api/rooms`, 입장은 `POST /api/rooms/:code/join`, 실시간 연결은 `GET /ws/:code?token=...`을 사용합니다.
