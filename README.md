# THE TIMELINE — 두뇌 서바이벌

혼자 진행하는 10문제 훈련과 2~8명이 실시간으로 승점을 겨루는 온라인 생존 게임입니다. 2인 대전은 10문제 결승, 3~8인 대전은 최종 두 명의 3문제 결승으로 이어집니다. 그 외 방은 본선 라운드마다 승점이 가장 낮은 한 명이 탈락하고, 마지막 두 참가자가 서로 다른 세 문제의 결승을 치릅니다.

## 실행과 배포

Node.js 20 이상에서 `npm ci`와 `npm run dev`를 실행하면 로컬 개발 서버가 열립니다. `npm run build`는 화면을 `dist/`에 복사합니다. Cloudflare 배포 설정은 `wrangler.jsonc`에 있습니다.

## 개인 훈련

방식을 1명으로 선택하면 개인 훈련이 시작됩니다. 논리·제약조건, 정보·확률 추론, 자원·전략, 기억·패턴 네 분야에서 한 번에 한 문제씩 총 10문제를 풉니다. 첫 네 문제는 네 분야를 골고루 다루고, 이후에는 현재까지의 풀이 성과가 낮은 분야를 우선해 문제 유형을 고릅니다. 같은 유형을 연속으로 내지 않으며, 같은 분야의 성과에 따라 다음 문제의 제한 시간을 늘리거나 줄입니다.

각 문제는 상황과 규칙, 목표, 제한 시간으로 안내하고 답을 제출한 뒤 풀이와 분야별 복기 포인트를 공개합니다. 훈련 리포트는 정답 일치율, 기억한 자리 수, 또는 가능한 최고 점수 대비 달성률을 보여주며 지능 평가로 사용하지 않습니다. 상대가 필요한 인디안 포커·경매·순위 추론은 개인 훈련에서 제외합니다.

## 문제 유형과 진행

라운드마다 완전정보와 불완전정보 분야를 같은 확률로 고르며, 직전 유형은 반복하지 않습니다. 숫자·배치·단서가 새로 생성되는 유형과 15개 상황 추리 문제를 합쳐 총 18개 유형으로 구성했습니다.

- 완전정보 퍼즐은 교차 수열, 기호 연립식, 순위·표식 관계 논리, 5×5 좌표 변환, 6×6 스도쿠, 5자리 암호 추론으로 구성됩니다.
- 불완전정보는 104장 더블덱 인디안 포커, 15개 상황·최적화 추리 문제, 가중 순위 추론, 8글자 반복키 암호, 표본 확률 분석, 5개 프로젝트 자원 최적화, 봉인 경매, 참·거짓 판별, 16자리 작업 기억, 턴제 타일 전략, 25개 후보 최단 경로, 8비트 상태 추론을 포함합니다.
- 각 유형은 선택형·정수·문자열·베팅·입찰 입력을 사용합니다. 인디안 포커의 중복 카드와 숨겨진 개인 정보, 경매의 비공개 가치, 전략전의 순차 타일 선택은 서버에서 판정합니다.
- 비공개 단서 문제에서는 게임 내 공개 대화로 단서와 협상 내용을 공유할 수 있습니다. 대화는 참가자 토큰으로 검증하고 240자 제한 및 전송 간격을 둡니다.
- 시간 초과 시 답을 제출하지 않은 참가자는 0점이며, 턴제 전략전은 차례가 지나가도록 서버가 남은 타일을 자동 선택합니다.
- 본선은 라운드 승점을 먼저 비교하고, 동점이면 누적 승점과 서버가 정한 무작위 순서로 탈락자를 정합니다.
- 방 최대 인원이 2명이면 게임 시작과 동시에 18가지 유형에서 중복 없이 10문제를 뽑아 결승을 진행합니다. 방 최대 인원이 3~8명이면 본선에서 두 명이 남은 뒤 유형 중 서로 다른 세 가지를 뽑아 결승을 진행합니다. 결승 누적 승점이 가장 높은 참가자가 우승합니다.

## 실시간 동기화

방과 게임 상태는 Cloudflare Durable Object 한 곳에서 관리합니다. 방 변경, 답안, 채팅, 턴 행동을 직렬 처리하고 게임 순번과 라운드 식별자로 오래된 제출을 거부합니다. WebSocket 재접속은 플레이어 토큰으로 기존 자리에 이어집니다. 타이머는 서버 마감 시각과 Durable Object 알람으로 처리합니다. 문제 형식이 바뀐 배포에서는 이전 형식의 저장된 방을 새 규칙으로 잘못 읽지 않도록 폐기합니다.

방 생성은 `POST /api/rooms`, 입장은 `POST /api/rooms/:code/join`, 실시간 연결은 `GET /ws/:code?token=...`을 사용합니다.
